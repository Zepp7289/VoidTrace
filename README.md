## 构建

依赖 KernelPatch 源码与 aarch64 交叉工具链：

```
make KP_DIR=/path/to/KernelPatch TARGET_COMPILE=aarch64-linux-gnu-
```

追踪目标（uid、段特征、断点偏移、最大步数等）当前为源码内常量，需按实际目标修改后编译
